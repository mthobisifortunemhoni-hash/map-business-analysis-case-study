# Map-business-analysis-case-study
## Managed Print Services (MPS) Business Analysis Case Study

## Project Overview
  This project simulates a Business Analysis assessment of an enterprise printing environment. The objective is to evaluate the current print infrastructure, identify inefficiencies,     and define requirements for a future Managed Print Services (MPS) solution.

## Objectives
* Assess current print environment (AS-IS)
* Identify business and technical requirements
* Define operational and service requirements
* Propose a future-state MPS solution (TO-BE)
* Support vendor evaluation and service design
  
## Scope

## This includes:
* Printers, scanners, and multifunction devices
* Print management systems
* User access and authentication
* Cost and usage analysis
* Security and compliance requirements

## Project Contents
* Stakeholder Analysis
* Current State Assessment
* Functional Requirements
* Technical Requirements
* Operational Requirements
* Security & Compliance
* Future State Design
* Communication Templates

## Role
* Business Analyst – Requirements Gathering & Solution Definition.
* Responsibilities include:

* Stakeholder engagement and requirements elicitation
* Current-state assessment and analysis
* Requirements documentation and validation
* Gap analysis and solution recommendations
* Future-state process and service design

## Conclusion
* The purpose of this case study is to demonstrate a structured Business Analysis approach to assessing a large-scale printing environment and defining requirements for a future   Managed Print Services solution.
